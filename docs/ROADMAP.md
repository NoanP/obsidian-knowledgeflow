# Roadmap after 1.0

1.0 delivers the independent task layer and a working capture → draft → review → publish knowledge workflow. These are possible subsequent updates, not already implemented features or automatic commitments.

| Candidate | Goal | Gate |
| --- | --- | --- |
| 1.1 | Native Obsidian and mobile validation in an explicitly approved disposable vault | User authorizes a separate test, existing Vault1 unchanged |
| 1.2 | Opt-in legacy-note linking and Web Clipper template integration | Preview source mapping, no destructive migration |
| 1.3 | Weekly reviews and extraction of proposed tasks from meetings | Explicit review; tasks only created via board workflow |
| 1.4 | Better knowledge retrieval and source-backed questions | Fixed representative question set and measured retrieval failures |
| 1.5 | Optional local semantic retrieval, possibly QMD | Demonstrated benefit, platform/resource measurements, graceful fallback |
| 1.6 | Optional AI provider and background processing | Separate provider/privacy/cost decisions, cancellation and retry design |
| 1.7 | Cross-device conflict tools and complete backup/restore UI | Restore tests; do not promise cross-device atomicity |

Do not introduce multiple competing task plugins, automatic whole-vault rewriting, a mandatory cloud database or decorative graph growth. Keep the eight home function tiles, a dedicated knowledge entry, gray surfaces and text-based knowledge review indicators.
